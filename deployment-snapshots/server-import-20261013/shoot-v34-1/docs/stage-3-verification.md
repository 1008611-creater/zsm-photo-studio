# 阶段 3｜外部能力接入底座验证

日期：2026-09-30。范围：产品仓库内的供应商无关契约、Mock 任务适配器与本地联调边界。

## 已完成

- SceneDocument 继续使用 1.1.0；新增 GenerationRequest、输入素材 provenance、输出规格和 Mock 任务字段，供应商任务格式没有进入产品核心合同。
- 图片和视频共用 provider-neutral generation adapter，canvasAdapter 单独保留为未配置能力；没有猜测无线画布、Toonflow、Arnis 或任何模型服务 endpoint。
- Mock provider 支持 queued → running → succeeded/failed/canceled，能够模拟无结果、超时、不可用、参数错误、不支持、配额不足和可重试失败。
- 幂等键会返回已有任务，避免重复提交；可重试失败会创建新的请求和任务 ID。Mock 结果的媒体类型、来源和成本状态均标记为演示/未知，不产生真实媒体或真实扣费。
- 服务能力清单明确区分 mock、disabled 和 configured。当前场景、图片、视频为 Mock；无线画布/导演台为 disabled，原因是尚未提供接口合同。
- 浏览器端仍没有凭证读取路径；本阶段没有创建真实 .env、支付账户、队列、持久化或云端媒体存储。

## 实际验证

- npm run typecheck：通过。
- npm run lint：通过；若存在提示，仅为现有客户端文件中的可读性告警，不影响构建。
- npm test：8 项通过，覆盖版本合同、请求结构、状态迁移、幂等、失败重试、无结果和取消。
- npm run build：通过，Next.js 静态页面构建成功。

## 边界与未验证

- 本阶段没有调用真实图像、视频、地图、Arnis、无线画布、Toonflow、支付或社媒服务；没有真实上游队列、webhook、取消保证、账本或跨设备持久化。
- 没有用户提供的渠道文档、精确模型 ID、价格、区域、回调和凭证注入方式，因此无法验证真实供应商能力、成本或商用授权。
- 未进行真机、Safari/iOS、屏幕阅读器和生产服务器压测；阶段 2 已记录的本地 Chromium 桌面/窄屏验收仍是当前 UI 基线。
- 当前浏览器界面沿用阶段 2 的 Mock 入口；失败/重试语义由 adapter 和测试覆盖，真实服务状态不应从 Mock 结果外推。

## 下一阶段最小资料

接入任一真实图像/视频或画布渠道时，集中提供该渠道的脱敏官方文档或调用样例、准确产品/模型 ID、请求与异步状态字段、回调签名规则、限流/计费/失败收费规则、区域和商用授权边界，以及服务端安全注入方式。部署和收费联调还需要三台服务器的脱敏职责与资源清单、链动小铺商户 API/回调/退款/沙箱资料。
