# Stage 11 verification record

Date: 2026-10-02 (Asia/Shanghai)

## 本阶段目标

为“旅行情侣写真”建立首批用户实验所需的反馈与匿名记录能力，不把实验功能误称为正式订单系统。

## 已完成

- 新增匿名实验数据契约：满意度、发布意愿、推荐意愿和可选文字反馈。
- 体验订单记录补充模板版本、模式、provider、完成时间、耗时、是否有输出和失败类别。
- 订单完成后可在当前会话中直接填写反馈。
- 新增“导出匿名记录”入口，导出 JSON 不包含原始照片、图片 URL、Base64、完整提示词、导演快照或身份信息。
- 新增 `docs/beta-runbook.md`，说明 10～20 名测试用户的招募、操作、记录、删除和决策标准。
- OpenLux 真实调用默认关闭；本阶段没有真实渠道请求。

## 实际检查

- `npm run typecheck`：通过。
- `npm run lint`：通过。
- `npm test`：通过，6 个测试文件、25 个测试。
- `npm run build`：通过；包含 `/studio` 和 `/api/image-generation`。
- 本地生产服务冒烟：`GET /studio` 返回 200；`GET /api/image-generation` 返回 200 且 `state=disabled`；服务已停止。
- 未调用真实 OpenLux、支付、视频、社媒接口；未部署、未 commit、未 push。

## 当前限制

- 订单和反馈仍是当前浏览器会话状态，刷新后可能丢失。
- 目前没有真实支付、账号、云端订单或对象存储。
- OpenLux 参考图、批量数量、长期 URL、正式报价和真实取消仍未确认。
- 尚未进行真实用户实验；10～20 个测试订单需要后续人工组织和记录。
