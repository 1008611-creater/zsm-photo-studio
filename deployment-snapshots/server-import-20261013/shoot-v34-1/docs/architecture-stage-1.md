# 阶段 1 架构决策记录

日期：2026-09-29。状态：阶段 1 原型决策，生产拓扑待用户资料和压测验证。

## 决策摘要

采用独立的 Next.js App Router + TypeScript 模块化单体。界面、契约和 mock 服务适配器放在同一应用仓库；不拆服务、不接 ANS 内部代码。目标域名 `zsm.cauai.fun` 只记为规划目标，未配置 DNS、反向代理或部署。

采用原生 Three.js 作为概念场景视口，而不是 Babylon.js 或 React Three Fiber：当前画面是自定义、低对象数的程序化灰白模，需要直接控制 renderer、几何、相机与交互；原生 Three.js 避免把业务数据绑到 React 场景组件体系。选择仅基于当前原型范围，尚无 Arnis 数据载入、真实地点画面质量或大场景性能基准；不能外推为正式渲染选型结论。

## 模块与边界

```text
app/                 Next 路由、根布局、全局视觉样式
components/          Studio 工作台与 Three.js 视口
app/lib/contracts.ts Zod 场景合同、任务/错误类型
app/lib/demo-data.ts 标记为 demo 的预设内容
app/lib/adapters.ts  场景、生成、额度、草稿存储 mock ports
docs/                产品蓝图、审计和架构决策
```

- `SceneDocument` 是供应商无关的传输边界，当前 `schemaVersion: "1.0.0"`。字段演进时需升版本并维护显式迁移器；不把 Toonflow 节点 JSON 当成产品持久合同。
- `SceneAdapter` 获取场景和来源信息；真实地理来源需要边界、坐标参考、署名/许可、捕获时间、精度/缺失提示。当前只返回演示场景。
- `GenerationAdapter` 接收场景快照及输出类型，未来负责排队和映射供应商异步状态；本地 mock 立即返回演示任务，不调用上游。
- `BillingAdapter` 仅返回虚构体验额度；未来额度预留/结算/失败返还需由服务端账本处理。当前没有账户、支付或真实余额。
- `StorageAdapter` 仅确认进程内演示草稿，不持久化。生产存储应保存账户/项目/场景版本/任务/账本元数据与私有媒体对象；数据库、对象存储、队列和 CDN 等服务器资料、余量及隐私要求明确后再选。
- 画布/导演台只通过后续版本化模板输入输出适配；未验证 endpoint 不编码。浏览器不承载产品服务端密钥。

## 数据、任务与错误

SceneDocument 含稳定 ID、版本、来源/地点、人物代理姿态/造型/变换、镜头相机参数/时长/运镜/备注。人物资产引用需待上传与许可策略确定；代理人偶不能冒充真人网格。

任务状态目标为 `queued → running → succeeded | failed | canceled`；失败可经用户操作重排。未来队列消息需含幂等键、场景版本、输出规格及关联 ID；重试、超时、供应商状态通过 adapter 归一化。当前只有类型和本地 mock，即时完成；无真实队列、webhook、持久化、取消或成本结算。

统一错误码覆盖验证、不可用、超时、额度不足、策略拒绝及未知错误。当前 mock 不产生供应商错误；未来日志不得包含凭证或不必要的原始肖像数据。

## 测试理由与完成定义

选原生 Three.js 是基于自定义低复杂度视口需直接控制 renderer/几何/相机，避免依赖 React 场景组件体系；尚未证明移动兼容、FPS、地理场景规模或发热。Vitest 覆盖版本校验、演示来源/媒体标识和 mock 适配器；桌面与窄屏浏览器仍需实际验收。Arnis 单地点 spike、任务/额度并发、服务契约、上传/删除 E2E、负载及无障碍检查均属后续。

真实模型接入待用户给定渠道文档、精确模型 ID、回调/限制/计费；支付待链动小铺商户 API、回调/退款和沙箱资料；部署待三台服务器脱敏资源与网络清单；画布/导演台互通待线上 build ID 和样例。阶段 1 不代表成熟收费产品或已上线。
