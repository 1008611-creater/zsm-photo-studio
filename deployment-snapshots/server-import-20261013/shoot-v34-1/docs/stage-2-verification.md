# 阶段 2 — 导演工作室闭环验收

日期：2026-09-29。范围：本地工作台原型，不连接真实上游服务。

## 本阶段结果

- 场景文档升级为 `1.1.0`，显式包含来源、精度、许可、社媒画幅、人物高度偏移，以及镜头景别、机位、人物动作、运镜、光线和构图说明。
- 三个场景均为程序生成的概念氛围场景；明确不是实际地理地点或地图数据。代理人物仅由项目基础几何组成，不是真人模型。
- 人物位置、朝向、高度、姿势和穿搭以及摄影机位置、目标点、视野均可编辑；选镜头后视口跟随该镜头参数。镜头可新增、删除、上移、下移，序号按顺序生成。
- 画幅预览支持 `9:16`、`3:4`、`16:9`，作为构图参考而非实际生成媒体。
- 导出两份文件：含完整 SceneDocument 的结构化 JSON，以及含场景 provenance、精度、许可、安全提醒、逐镜参数的可打印 HTML 分镜文档。HTML 可由浏览器打印或另存为 PDF。
- 草稿只存在 React 当前页面会话内；没有使用 localStorage、云端存储、账户同步或版本恢复。重置会清除当前会话的镜头与任务并恢复示例。
- 图片/视频演示任务走本地 mock，标注 Mock，不调用模型，也不生成可冒充成片的媒体。

## 验收记录

- `npm run typecheck`：通过。
- `npm run lint`：通过。
- `npm test`：5 项通过。
- `npm run build`：通过，首页静态预渲染成功。
- Playwright 真浏览器主路径：切换至“山间来信”→ 调整人物姿势 → 改镜头标题并下移 → 导出 JSON 和 HTML。读取导出文件确认镜头顺序、版本、画幅、安全/许可及概念来源提示均存在。
- 视口宽度：桌面 1280px、手机 390px 与 360px；检查 `scrollWidth === clientWidth`。在 390px 实际切换到镜头编辑，在 390px 与 360px 实际触发两份导出下载。
- 浏览器控制台无错误或警告。测试环境为本地 Chromium，非真机、非 Safari/iOS。

## 未验证 / 后续门槛

- 未验证真机触控、辅助技术屏幕阅读器、系统减少动态效果开关的手动体验。
- 错误边界与重试逻辑已实现，但当前 mock 成功任务无法自然制造上游错误；此处未验证真实服务失败/恢复。
- 未连接真实地图、Arnis、无线画布、Toonflow、图像/视频模型、支付、社媒发布、云端存储或账号系统。
- 下一阶段本地原型没有阻塞项。真服务联调前仍需用户提供已选渠道的接口文档/调用示例、支付沙箱资料、地图数据来源与许可边界，以及脱敏后的服务器职责和部署结构；本阶段不需要这些资料。
