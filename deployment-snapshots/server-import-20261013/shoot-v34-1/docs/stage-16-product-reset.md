# 阶段 16：结果型产品入口重构

日期：2026-10-02（Asia/Shanghai）

## 为什么重做

阶段 15 的 `/studio` 已能演练导演台和 Mock 任务，但默认入口仍然把场景、镜头和服务状态放在第一屏。用户看到的是工作台原型，而不是“上传照片后得到一张可分享图片”的产品路径。本阶段暂停付费和商业化，把快速模式重构为结果优先的创作入口，专家导演台保留为进阶能力。

## 已实现

- 默认快速模式改为三步叙事：上传照片 → 选择风格/画幅 → 生成预览。
- 三个项目样片继续用于风格参考，明确写为参考样片，不伪装成用户成片。
- 新增“样片 / 你的照片 / 结果”三栏视觉状态：未上传、仅本地预览、Mock 完成、真实结果分别有不同文案。
- 上传入口加入 JPG、PNG、WebP 类型与 8MB 大小校验；选择文件只创建本地预览，不自动上传。
- OpenLux 服务端路由已建立一次性 multipart 参考照边界：只有真实调用开启、用户确认费用且明确确认发送参考照时才会发送；不写入日志或长期存储。
- 快速模式隐藏导演台参数，把提示词放入可选的高级折叠区；专家模式仍保留场景、人物、摄影机、镜头和任务快照能力。
- 快速模式提供体验预览/真实生成状态切换，但默认保持 Mock；未配置或未授权时不会向 OpenLux 发请求。
- 3 个画幅按钮和生成服务状态都具有可见选中态、禁用态和下一步说明。

## 真实边界

- Mock 仍只产生状态占位，不产生可下载的图片成片。
- OpenLux 真实开关和支付仍未在本阶段开启；参考照的真实发送路径已实现但未调用。
- 真实结果区只有在 provider 返回可交付图片 URL/Base64 后才显示图片；样片和本地参考图不会被标成真实结果。
- 场景仍是程序生成的概念氛围，不是实际地点还原。
- 任务和匿名订单仍按阶段 14/15 的当前会话边界处理。

## 下一步闸门

先让真实用户看懂并完成快速模式，再决定是否开启真实 OpenLux 参考图生成。不要在没有用户反馈前扩展视频、支付、真实地图或更多导演台参数。
