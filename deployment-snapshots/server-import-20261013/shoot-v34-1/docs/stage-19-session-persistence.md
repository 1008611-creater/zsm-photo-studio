# 阶段 19：匿名会话连续性验收

日期：2026-10-05（Asia/Shanghai）

## 浏览器验收

- 在快速模式提交一次 Mock 体验后，订单面板显示匿名订单编号、渠道和耗时。
- 选择满意度 5、发布意愿“愿意”、推荐意愿“愿意”，刷新页面后这些结构化反馈仍然保留。
- 补充反馈自由文本不会写入 `sessionStorage`，刷新后清空；这是隐私边界，避免匿名实验记录长期保存用户自由文本。
- 内置 CozyClay 刷新时对 `/agent/sessions` 与 `/agent/sessions/:id` 的可选云端探测收到 HTTP 200 的 `disabled` 响应，不再产生 404 控制台错误。
- “清除记录”仍只清除当前标签页的匿名订单数据，不触碰图片临时链接或 CozyClay 本地项目。

## 自动化验证

- 已有订单契约测试覆盖：结构化反馈可保存，补充自由文本不会写入会话存储。
- 本阶段新增的两个 disabled 路由已在生产构建后复核：`GET /agent/sessions` 和 `GET /agent/sessions/test-id` 均返回 HTTP 200；未启用云端会话、登录或模型能力。

## 边界

- `sessionStorage` 不是生产订单系统，也不支持跨设备、跨标签页或账户同步。
- 未导入用户照片、未调用真实模型、未支付或发布内容。
