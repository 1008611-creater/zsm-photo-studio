# Stage 10 verification record

Date: 2026-10-02 (Asia/Shanghai)

## 目标

把“旅行情侣写真”收敛为一个可演练、可交付的图片产品闭环：模板选择 → 导演方案 → 本地参考照预览 → 生成闸门 → 结果保存入口 → 当前会话订单记录。

## 已完成

- 快速模式明确展示首发产品定位和三个现有概念模板；专家模式继续保留导演台编辑能力。
- 新增 Mock / OpenLux 实测切换。默认 Mock；OpenLux 只有在服务端 readiness 为 `configured`、用户勾选费用确认且没有未确认的参考照时才允许提交。
- OpenLux 产品请求固定使用已经受控验证过的组合：`gpt-image-2.5-sunburst-c`、`1024x1024`、`low`、`webp`、`url`。
- 真实请求继续只经过 `/api/image-generation`，浏览器不接触 API Key。当前真实调用开关保持关闭。
- 参考图片只做浏览器本地预览、替换和移除；本阶段不会上传，也不会写入任务快照或日志。
- 新增当前会话体验订单记录，记录模板、镜头、生成方式和交付状态；不宣称云端保存、支付完成或跨设备同步。
- OpenLux URL 结果支持打开/保存入口，并标注为临时渠道 URL；没有擅自加入对象存储或长期代理。
- 扩展图片输出格式契约以容纳已确认的 `webp`，保持供应商字段不进入导演台核心数据结构。

## 实际检查

- `npm run typecheck`：通过。
- `npm run lint`：通过。
- `npm test`：通过，5 个测试文件、23 个测试。
- `npm run build`：通过；包含 `/studio` 和 `/api/image-generation`。
- 本地生产服务冒烟：`GET /studio` 返回 200；`GET /api/image-generation` 返回 200 且 `state=disabled`；服务已停止。
- 未进行真实 OpenLux 请求；没有支付、视频、社媒发布、部署、commit 或 push。

## 未完成与边界

- 本阶段没有接入真实支付、订单后端、用户账号、对象存储或跨设备历史。
- `sunburst-c` 当前只把一次真实成功调用登记为证据，不代表 9:16、批量 `n=4`、参考图、长期 URL 或取消/轮询能力已确认。
- 结果 URL 仍可能临时失效；用户需要及时保存。下载是否被上游 CDN 允许仍未做跨域验证。
- 真实浏览器只完成生产服务冒烟，未在本阶段再次授权并执行真实付费调用；OpenLux 真实路径仍需单独的费用授权和正式订单验收。

## 下一道闸门

先用 Mock 完成 10～20 个用户体验订单并记录模板表现、生成耗时、失败率、分享意愿和成本；达到阶段指标后，再单独申请一次真实产品路由调用和正式支付接入。
