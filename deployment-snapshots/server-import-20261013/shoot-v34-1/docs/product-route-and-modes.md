# zsm-photo-studio 产品路由与双模式设计

状态：已确认产品方向，具体域名反向代理和 ANS 入驻配置待后续提供。

## 产品归属

- GitHub 仓库：`zsm-photo-studio`
- 主站：`zsm.cauai.fun`
- 推荐产品子路径：`/studio`
- 预留模式路径：`/studio?mode=quick`、`/studio?mode=expert`

不拆成两个前端项目，也不为快速模式和专家模式维护两套视觉。`zsm-photo-studio` 负责工作台、场景数据、导演台交换协议和图片生成适配边界；主站只负责入口、导航、账号/项目上下文和未来收费承载。

## 双模式原则

### 快速模式：模板化交付

面向第一次使用、社媒发布和希望快速得到结果的用户。

- 从旅行、情侣写真、穿搭三个首发模板开始。
- 模板预设场景、人物代理、服装、光线、镜头序列和社媒画幅。
- 用户主要完成：上传参考照片、选择模板、替换少量参数、预览、提交图片任务、下载素材。
- 只展示不会破坏结果的安全控件；复杂场景编辑、底图通道、深度/法线、镜头细调收进专家模式。
- 每个模板必须显示来源、许可状态和“概念场景/Mock/真实结果”边界。

### 专家模式：导演台控制

面向摄影爱好者、自媒体创作者和需要精确控制的用户。

- 可编辑场景、人物代理的位置/朝向/高度、姿势/穿搭预设和摄影机参数。
- 可增删排序镜头，编辑景别、运镜、光线、动作、备注、画幅和输出规格。
- 可查看并导出 plate/depth/normal、相机 JSON、提示词和拍摄沟通包。
- 可接入 CozyClay 导演台的受控导入/导出桥接；未提供构建地址时保持 disabled，不伪装成已接入。
- 可查看任务状态、输入来源、许可状态、规格和成本未知提示，但不能绕过服务端能力和账户权限。

## 统一视觉与交互

- 快速模式和专家模式共用同一品牌、色板、字体、按钮、提示、错误和无障碍规则。
- 模式切换不丢失当前草稿；只改变可见控件和解释层级。
- 快速模式中的“更多控制”入口切换到专家模式，并保留当前场景/镜头上下文。
- 专家模式回到快速模式时，只隐藏高级控件，不删除用户数据。
- 移动端默认快速模式；专家模式仍可浏览、编辑镜头和导出，但采用分步面板避免横向溢出。

## 能力边界

模式不是安全边界。前端隐藏按钮不能代替服务端鉴权；未来账户、套餐、额度和项目权限必须在服务端再次校验。当前阶段没有真实账户、支付或云端持久化，因此只实现本地模式切换和能力描述，不宣称收费权限已生效。

## 首发信息架构

```text
zsm.cauai.fun
└── /studio
    ├── 快速模式（默认）
    │   ├── 模板选择
    │   ├── 参考照片
    │   ├── 轻量预览
    │   └── 图片生成与下载
    └── 专家模式
        ├── 场景/人物/摄影机
        ├── 镜头时间线
        ├── 导演台素材包
        └── 高级图片任务参数
```

## 当前实现顺序

1. 先在现有仓库内完成统一壳层和本地双模式切换。
2. 将快速模式接到现有 Mock 图片任务和三个首发模板。
3. 将专家模式接到现有 `SceneDocument`、镜头编辑和导出包。
4. 用户提供 CozyClay 构建地址/版本后，再实现 iframe 或文件交换适配。
5. 用户提供 Openlux 服务端合同和凭证注入方式后，再接真实图片 provider。
