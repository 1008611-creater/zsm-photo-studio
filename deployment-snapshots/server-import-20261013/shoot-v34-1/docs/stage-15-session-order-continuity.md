# 阶段 15：匿名体验订单连续性

日期：2026-10-02（Asia/Shanghai）

## 完成内容

- 把体验订单元数据抽成独立契约：模板、镜头、模式、provider、状态、耗时、失败码和临时结果有效期。
- 订单生成后显示匿名订单号后 8 位，便于测试用户反馈和人工对照。
- 使用浏览器 `sessionStorage` 保存最多 20 条匿名订单元数据，刷新页面仍能恢复；不保存提示词、导演快照、原图、Base64、渠道 URL、凭证或反馈自由文本。
- 增加“清除记录”入口，清除只作用于当前浏览器标签页的匿名记录。
- 结果链接仍由服务端进程内临时登记控制；刷新后订单元数据可见，但临时图片链接可能因服务重启而失效，界面保留这一边界。
- 导出功能继续只导出匿名实验记录，不导出媒体和用户素材。

## 未宣称的能力

- 没有登录、实名用户账户、支付订单、跨设备同步或云端作品库。
- `sessionStorage` 不是生产持久化；关闭标签页、清理站点数据或换设备后记录会消失。
- 没有把“已交付”当成支付完成，也没有自动重试真实渠道任务。
