# Prompt 04 — 封闭测试、收费验证与上线准备

在可运行 MVP 与已验证服务之上准备小范围封闭测试。先核对目标地区、隐私/内容/平台要求与部署环境；法律合规事项标出需专业审阅的问题，不伪装为法律结论。没有用户明确授权不得正式上线或启用真实收费。

任务：实现可审计的额度预留/结算、失败补偿、费用确认与支出上限；补项目导入导出和删除；上传资产权限/保留期限；分享链接范围与撤销；举报与下架通道；运营告警和无敏感数据的日志。编写端到端冒烟、弱网/任务超时/上游失败/重复回调/权限穿透测试。验证手机、桌面、辅助访问、负载和成本。

准备招募目标用户的访谈脚本和不夸大能力的产品演示；衡量首次完成、导出率、复用、生成成本、错误率和付费信号。小红书/抖音/闲鱼文案只生成草稿；内容须披露合成媒体，需实际确认平台规则后才能上架或发布。

输出发布清单：部署变更、数据备份/恢复、回滚、责任人、定价/退款政策、服务条款与隐私说明、内容处理与客服流程、真实费用账单样例。仅在用户逐项明确授权后执行外部写操作、部署、公开发布或收费开通。
