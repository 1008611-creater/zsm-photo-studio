# Prompt 03 — 外部场景、画布与图/视频服务适配

仅在用户已提供准确 repo/API 文档、可用测试凭证的安全注入方式、授权许可和成本限制后开展。先核实候选模型/服务的当前官方接口和本账户可用性；任何未确认能力都保留为 disabled，并向用户指出缺项。密钥绝不可进入源码、浏览器包、日志、截图、提交或问题报告。

基于产品的 provider-neutral adapter，为经确认的 Arnis 场景源、现有无线画布 workflow、图像模型、视频模型分别添加隔离接入层。实现功能探测、严格输入校验、server-side secrets、预估费用与用户确认、异步队列状态、幂等回调、错误映射、重试/取消规则、资产来源和授权记录、配额与用量台账。避免公开高精度私人地点或未经许可的人物素材。

先在沙箱项目和 mock provider 上跑通，再经用户允许使用付费/生产账户。提供契约测试和去密钥的端到端测试。记录模型/服务的精确官方名称、访问区域、文档核验日期和关键能力；不要使用名称相似来推断型号。仅保存确实需要的用户素材并提供删除行为测试。
