# 阶段提示词使用说明

这些是给 Codex 或其他代码代理的可复制提示词。项目目标是交付一个完整、可公开收费的产品；阶段用于依赖审计、架构决策、实现和上线验收，不把中间骨架或单点 Demo 当作最终交付。每个阶段要求代理读取目标仓库的 AGENTS.md、先列证据和变更计划、遵守仓库约定、保留用户改动、运行适当验证，并清楚说明未验证项。

产品身份：ANS（`ans.cauai.fun`）是 AI 社区，产品计划作为学生创业项目入驻/展示；独立产品目标域名是 `zsm.cauai.fun`，工作名暂建议“取景簿”。产品代码仓库为 `1008611-creater/zsm-photo-studio`（private），与 `ans-platform` 社区源码分开管理。

- [新对话总控提示词与当前下一步](docs/prompts/START-HERE.md)

**按依赖顺序完成全部阶段，最终以一体化首发验收为准。** 阶段 0 的证据会决定后续技术选型；若发现现有服务改变方案，先更新蓝图再继续，不因此削减用户已确认的完整产品目标。真实模型调用、支付、创建/公开仓库、外发、push、正式发布和部署各按本次明确授权执行。

- 阶段 0：仓库、Arnis、画布、导演台和模型能力审计。
- 阶段 1：架构决策记录和端到端技术切片/骨架。
- 阶段 2：创作工作台可用 MVP。
- 阶段 3：真实地图/Arnis/无线画布/图像和视频适配器。
- 阶段 4：付费验证、可靠性、内容与封闭测试上线准备。
