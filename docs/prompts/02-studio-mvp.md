# Prompt 02 — 导演工作室与首条价值闭环

沿用已批准架构，构建完整收费首发的核心工作室流程：“选择场景 → 布置人物/机位 → 编排镜头 → 生成照片/视频 → 整理发布素材”。分镜导出是交付物之一，不是产品终点。开始前先检查仓库指令、当前分支与改动，避免覆盖用户文件。

实现要点：真实地图或场景数据接入必须有 provenance 字段；数据暂不可用时提供标注清楚的示例/概念场景。视口至少支持旋转/缩放/取景切换；人物用许可清楚的代理资源，支持移动/旋转/高度和动作/姿势预设；相机支持位置/目标/视野、景别/机位预设；分镜卡支持镜号、时长、动作、运镜、光线和创作备注，并在 viewport 中选择对应镜头。

导出一份适合实际拍摄沟通的分镜包：地点/数据精度提示、镜头顺序、构图/机位/动作、平台画幅、安全/许可提示。支持 9:16 等社媒画幅，但仅生成草稿与文件，不调用社媒发布接口。项目保存、版本恢复和删除要按已批准数据策略处理。

验收：一个非技术目标用户能在没有口头解释的情况下在 10 分钟内完成示例任务；键盘基础可操作；移动端至少可以浏览、编辑镜头和分享/导出；空态、加载、数据缺失、失败态齐全；演示占位明确而不冒充真实模型结果。按现有 repo 运行测试，并提供桌面/移动验收步骤和尚未实测项。不得自动 push/部署。
