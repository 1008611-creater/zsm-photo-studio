# 风险、权利与上线门槛

## 主要风险

- **错误还原/导航风险**：OSM、地形数据和生成内容不等同于实时、完备的真实环境；不可把作品预演包装成导航或现场准入保证。
- **许可与知识产权**：代码仓库、Minecraft 品牌/资源、地图/高程源、3D 人物资产、字体、模型输出分别查许可与署名要求；记录 provenance。
- **肖像与隐私**：照片、脸部/身体、婚纱照与未成年人属于敏感场景。只接收有权处理的素材；设定默认短保留期、删除入口、访问控制与明确同意；禁止把用户照片用于模型训练，除非用户针对独立目的明确选择且确有可执行机制。
- **虚假营销/冒充真人**：清楚标注 AI 合成、概念预演和合成媒体，不制作未经同意的真人裸露/欺骗性深伪，不承诺社媒涨粉。
- **生成与地图成本**：面积、分辨率、重试次数和视频秒数形成成本；需硬配额、用户确认、费率上限和失败退还政策。
- **开放上传输入**：校验文件类型/大小、恶意载荷、访问控制、预签名 URL 生命周期；API key 仅服务端密管。
- **平台/支付条款**：社媒内容标识、闲鱼服务上架规定、支付/退款与消费者保护要求上线前核实。

## 上线门槛

- 仓库和 OSS/数据/资产许可已清点；可披露来源和署名。
- 任何第三方凭证不入仓，部署环境使用 secrets manager；日志屏蔽敏感内容。
- 用户上传、生成、删除、导出和数据保留说明真实可执行；公开分享需明确控制权。
- 额度、计费、错误和退款行为经测试；大额生成二次确认。
- 真实人物与生成内容标识、投诉/下架入口和内容处理流程到位。
- 端到端测试覆盖登录/项目/失败任务/结果/删除；移动端与桌面性能通过实测。
- 明确服务地区、隐私政策、服务条款和联系渠道；涉及法律适用问题由合格专业人士审阅，本清单不是法律意见。
- 外部公开发布、GitHub push、线上部署、收费开通必须在你明确授权后执行。
