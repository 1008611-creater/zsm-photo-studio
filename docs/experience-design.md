# 体验与视觉方向

## 产品感受

像一个懂社媒的数字片场，而不是“把各种 AI API 放在一起的仪表盘”。第一屏让用户看见地点场景、人物、机位和最终输出之间的因果关系；体验顺序自然是“灵感 → 预演 → 拍摄/生成 → 发布素材包”。

## 视觉语言

- 关键词：电影片场、真实地形、编辑部灵感册、空间感、轻盈、可信。
- 桌面创作台：大幅场景视口；左侧轻量项目/场景导航；右侧分层检查器（演员、道具、镜头）；底部可收起镜头卡/时间线。避免黑底密集遥测面板式“AI 科技感”。
- 用户入口与灵感浏览可以明亮、温润、杂志化；创作视口可用中性深色以突出场景。色彩、圆角和字体先做可访问的 token，待实际品牌探索再锁定。
- 移动端主做灵感浏览、预览、分享和轻编辑；复杂场景编辑可提示在桌面继续，而非硬缩小桌面 UI。
- 摄影术语同时给直观说明和快捷预设：近景/全身、机位高度、镜头移动、光线、拍摄姿势。
- 空/错/慢状态要有明确下一步。地图数据不齐时提供“概念场景”路径，明确标识来源与不确定性。

## 关键页面

1. 落地页：15 秒价值演示、真实使用样例、开始创作/查看示例。
2. 灵感/地点页：主题、区域、许可/数据说明；不冒充真实可拍地点推荐。
3. 项目新建：平台/题材/地点/输出类型逐步填写，支持稍后再选。
4. 场景工作室：viewport、演员与姿势、摄像机、shot list、渲染质量、导出。
5. 结果与分享：社媒尺寸方案、项目只读链接、拍摄清单/提示词；平台文案为草稿。
6. 项目/素材/额度页：删除、保留期、生成消耗清楚可见。

## 差异化的演示点

同一地点在“地图/地形 → 灰白模 → 搭好人物机位 → 竖屏成片参考”间切换；如果精致的逼真渲染不可行，先用干净好看的模型灰白模 + 摄影机取景框 + 有层次的分镜卡，而不是播放一个假的成片视频。

## 设计验收

- 360px 手机浏览无横向溢出，核心预览可看，按钮可触达；桌面工作室优先支持常见 1280px 宽度。
- 用户能明确区分场景模型与成片、规划位置与实际许可、AI 生成与照片事实。
- 关键操作可键盘访问；状态、对比度和减少动效模式可用。
- 所有展示结果要么真实产出，要么清楚标为 demo/概念图；不得用假客户/假转化指标营造已上线错觉。
