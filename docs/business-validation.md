# 商业验证与内容增长

## 待验证的商业假设

- 对普通创作者，核心付费价值也许不是“AI 图更多”，而是减少踩点和拍摄构思时间、让用户更敢出镜并获得可执行的机位指导。
- 地点联动能形成分享传播：用户分享场景分镜/拍摄前后对比 → 带来相似审美的创作者 → 进入可复用模板/地点页。
- 高成本视频生成应该放在付费升级，而不是免费首页即开全量视频；免费层用模板、灰白模预览和有限概念图体现价值。
- 摄影师/工作室可能购买多人项目和客户提案，但要与 C 端订阅分别测试。

## MVP 变现试验

- 免费：查看公开 demo、有限场景/分镜创建、带标识的低分辨率预览（具体额度按实际成本算）。
- 单次包/积分：单项目精修或视频生成，不让每次重试隐性扣费。
- 创作者订阅：每月明确额度、商用授权范围、项目数、导出规格与超额价格。
- 工作室席位：客户项目、品牌模板、提案导出与团队权限；有客户访谈后再定。

不得在实测 API 单价、失败计费和支付手续费前写具体盈利承诺或“无限生成”。

## 早期调研

访谈 8–12 位来自至少三类目标人群的用户（穿搭/旅行创作者、Cosplay/摄影、写真/婚纱潜客）。不先问“你会不会用”，让其讲最近一次拍摄怎么找地点、如何摆姿势、总耗时、失败原因和付费支出。展示可运行原型，观察是否能独立完成，再做不同付费包装的选择测试。

## 小红书/抖音内容测试

内容系列：

- “同一个真实地点，出片机位可以这样选”：地点 → 3D 机位 → 实拍/概念预演对比（清楚标真假）。
- “不敢摆姿势？把一张参考姿势放进场景预演”：只展示有授权的人物与结果。
- “摄影师脑内的分镜变成可保存的 shot list”：过程型产品演示。
- “城市角落的电影感”：用户投稿/可许可地点 + 场景复原限制说明。

测试不同钩子和内容形式，记录收藏、转发、评论中明确痛点、落地页点击、首个项目完成；不伪造平台热度、不自动群发。闲鱼定位先测试“数字拍摄企划/场景预演服务”是否符合平台规则，再决定是否上架，避免描述为线下拍摄许可、成片保证或规避平台限制。
