# 首发产品定义

## 产品愿景

产品工作名建议：**取景簿**（待用户拍板，商标/域名/平台重名未核验）。候选备选：**拾景**（更偏灵感社区）、**镜游**（更偏场景探索）。这是独立产品，目标域名为 `zsm.cauai.fun`。它计划作为学生创业项目入驻 ANS AI 社区；`ans.cauai.fun` 属于社区平台，不是本产品域名。GitHub 上的 `1008611-creater/ans-platform` 是 ANS 社区平台代码库；本项目独立私有仓库已建立为 `1008611-creater/zsm-photo-studio`，当前包含产品蓝图和执行提示词。

目标是建设面向中国创作者的完整收费网站产品。当前只有规划材料与 Arnis/候选工具的只读盘点，尚未在产品仓库实现或部署。

一句话：用户选一个地方或预设场景，安排自己/情侣/模特与镜头，获得想要的旅行、情侣写真或穿搭照片与短视频，并拿到适合小红书发布的内容素材包。

## 用户及范围

- 国内用户；小红书优先，抖音与闲鱼作为后续分发/获客渠道。首发核心题材：**旅行、情侣写真、穿搭**。
- Cosplay、写真、婚纱照、摄影爱好者、自媒体博主等都是重要扩展人群，按素材版权、真实身份一致性、成本和需求排序逐步加上，不从产品视野中删掉。
- 用户要的首发目标是完整结果（图片、短视频、场景/拍摄方案和发布素材包）。研发可分阶段推进，但阶段最终汇聚为一个完整收费产品，不把分阶段 Demo 当成最终交付。

## 核心体验

1. 挑地点：在地图选真实地点，或从预设精选地点/主题 3D 场景中挑选。可先有真实地点的方块世界/灰白模预览，再提供审美更强的 3D 场景库。
2. 搭片场：浏览场景，选择演员模板/本人或伴侣的授权参考素材，设置姿势、穿搭、道具、光线和摄影机。
3. 导演台：通过镜头卡/镜头编排/相机视角预演，保存一组连续画面；现有 Toonflow director3d node 是优先考察的复用候选。
4. 出作品：明确选择生成写真图片、短视频或旅行/穿搭/情侣内容包，先展示可预期的服务与额度，再排队生成。
5. 社媒交付：优先小红书的竖屏/图文尺寸、封面、标题、文案和话题草稿；不承诺平台流量，不在未授权前自动发帖。

## 首发页面与交付

- 品牌落地页/灵感场景库：以可播放的真实产品演示解释地点→片场→照片/视频价值。
- 地点与主题选择：地图选址 + 编辑精选的预设 3D 场景；地图数据分辨率、更新时间和缺失建筑清楚可见。
- 创作工作台：3D 视口、人物/穿搭/道具、导演相机、镜头序列、图/视频产物目标选择。
- 作品生成/任务中心：任务状态、耗时估计（有数据后）、扣额确认、失败处理、结果下载。
- 社媒素材包：原始图片/视频、裁切版本、封面与文案草稿。
- 我的项目、素材管理、账号/额度、服务与隐私说明、问题反馈。
- 国内支付：计划先接用户指定的“链动小铺”第三方支付；具体供应方、商户后台/API/回调协议、签约和合规情况未核实，不能先写支付代码或假定兼容。支付宝/微信为后续选项。

## 产品决策

- 不局限只做“实拍分镜工具”：目标是让用户得到需求中的照片/视频；分镜和场景编辑是生成更可控、结果更有特色的上游创作体验。
- Arnis 的 Minecraft 方块世界是潜在特色场景模式，而非默认的最终写真渲染器。为覆盖浪漫旅行、情侣和穿搭美学，可并列提供专业精选 3D 场景，避免强迫所有用户接受方块视觉。
- 真实地点选择与场景“可拍”只是视觉预演；地图不能证明当下可进入、拍摄许可、营业时间或安全。
- “成熟收费产品”是目标，不是已经具备收费/上线条件的事实。账户、额度、退款、任务并发、肖像隐私、平台内容规范和模型成本均需在正式收费前验收。
